## 目标与架构

Vue 3 + TypeScript + Vite + Element Plus + Vue Router。单一认证状态 composable 足够，不额外引入 Pinia。原生 fetch 封装超时、credentials、CSRF、结构化错误；按 auth/activity/registration 分模块。页面按路由懒加载，Element Plus 按组件导入。

登录、工作台、活动列表、创建/编辑、详情/名单、403、404。所有数据来自现有 API。三种活动状态严格遵循 M1.2；名单只显示 M1.3 实际返回的学生编号、状态与时间，不增加学生个人信息接口。Dashboard 使用服务端列表 total 统计三个状态和总数，展示最近创建活动及其真实人数，不把一页人数伪装为全局人数。

开发 Vite 同源代理 /api 到 loopback 后端，不关闭 CSRF，不增加 CORS 通配。测试启动器固定 test-app、127.0.0.1:3307/campushub_test，仅显式 -Apply 启动。演示密码由用户自行输入；自动化仅在本机内存读取既有受限凭据，不记录请求体、Cookie、trace 或密码截图。

## 设计决定

采用校园活动编排工作台：白色导航、冷灰画布、Indigo 主操作，近期活动以日期签形成识别特征。无需图片、图表或无效入口。系统中文文案，北京时间，窄屏导航收缩、表格自身横向滚动，表单保持文档滚动。详见根目录 DESIGN.md 与 UX-CONTRACT.md。

## 重点风险与验收

跨账号遗留数据：401 立即隐藏业务页面，内存草稿仅原身份恢复，退出清除。跨请求响应乱序：AbortController 和请求序号防覆盖。时间：输入和展示固定 UTC+08:00，发送带时区整秒。版本冲突：不重试、不静默覆盖，用户可保留编辑或重新读取。创建超时：结果未知，提示回列表核实，禁止自动重放。
