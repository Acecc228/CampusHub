## 实际读写与保留现场

`Test-DatabaseBootstrap.ps1 -Apply` 只以 test-migrator 在 `campushub_test` 创建 `m10b_unicode_probe`，提交一条包含中文、雪人、emoji、补充平面汉字和组合重音的记录。新连接逐字比较读回文本和 UTF-8 十六进制字节，全部相同。另一个事务插入 id=2 后 ROLLBACK，新连接仅见已提交的 id=1。

验收表及 id=1 保留作为证据；没有 DROP、TRUNCATE 或清理操作。开发库仍无表，没有 Flyway 历史表或业务表。后续迁移设计须明确处理测试库已经非空的事实；不得为通过迁移检查自动 baseline、clean 或删除验收表。

初始化和写入验收均只执行一次，不可用重跑覆盖证据。需要复查时使用 `Test-MySql84.ps1 -Stage Bootstrap` 和只读 SQL。`Test-DatabaseBootstrap.ps1` 无参数只预览；再次 `-Apply` 应在发现已有验收表时失败，不接管已有表。

预期拒绝测试生成的受限 diagnostics 文件包含 1044 / 1045 / 1142 等分类，不含原始错误、SQL 或密码；这些预期失败按上方验收结果判定，不是初始化失败。
