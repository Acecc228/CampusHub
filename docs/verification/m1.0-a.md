## 安全边界与剩余风险

- 本轮没有下载/运行安装包，没有创建 runtime、凭据、数据库或 Windows 服务，没有执行任何 `-Apply`、ACL 变更或 MySQL 写操作。
- 原配置 SHA-256 为 `1253B6E07E8CF0323D093EE21C50A02FF5B06585B4060C6F18C9C65F91F7263F`，只读对比未变；这不等于完成原数据库业务功能验收。
- 默认预览及危险命令扫描能够发现部分错误，不构成形式化安全证明。实际服务注册、Windows DLL、ACL 继承、MySQL SQL/权限仍需安装后验证。
- 官方 MD5 已固定，但实物安装包还没下载校验；MD5 不是数字签名。必须通过官方 HTTPS 下载并记录本地 SHA-256。
- 安装及 SQL 初始化可能部分完成后失败。脚本停止并保留现场，不自动删除、重置、清空数据或重复初始化。
- 本地凭据文件依赖 NTFS 保护；管理员及项目开发者可读取。后端不得继承 root 或 migrator 凭据。
- `Grant-ApplicationAccess.ps1` 只核对目标实例及业务表存在，不是 Flyway 验证器；必须先取得独立迁移的 validate/info 成功结果。
